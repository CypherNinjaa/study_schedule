Command palette

The fastest way to do anything. One keystroke opens a search box that jumps to any page, creates tasks, starts a timer, and runs common actions — without touching the mouse.

Opening it

Press Ctrl + K anywhere in the app (⌘ + K on Mac). The palette appears; start typing and results filter instantly. Press Esc to close it.

This documentation site has its own search on the same shortcut — press Ctrl + K here to try it. Inside the app, the palette does more: it also runs actions, not just navigation.

What you can do from it

  • Navigate — jump straight to Dashboard, Tasks, Study, Analytics, any page.
  • Create — add a task, start a study session, or log a habit without leaving where you are.
  • Start a timer — kick off a Pomodoro in one command.
  • Search your data — find a specific task, subject, or note by typing part of its name.
  • Run quick actions — toggle the theme, open settings, export data.

Using it well

  1. Type intent, not menus

    Just type "add task," "study," or a subject name — the palette figures out what you mean.

  2. Use the arrow keys

    Move up and down the results with ↑/↓ and press Enter to run the highlighted one.

  3. Make it your default

    Once it's muscle memory, the palette is almost always faster than clicking through the sidebar.

Learn one shortcut, save hours

If you only memorise a single thing in this app, make it Ctrl + K. See the full list on the Keyboard shortcuts page.
