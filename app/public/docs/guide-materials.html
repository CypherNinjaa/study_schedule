Study Materials

Organize your lecture notes, textbook PDFs, video playlists, and reference links in one private, searchable library.

Local-first asset management

The Materials tab is built on top of the browser's File System Access API and IndexedDB. It stores references and secure handles to your files on disk without uploading anything to remote servers or duplicating gigabytes of data.

Adding study materials

You can add materials using three convenient modes:

  1. Select local file

    Click "Choose file" to pick any document from your computer. The app saves a local handle so you can launch it with one click anytime.

  2. Web link

    Enter any URL to bookmark study articles, videos, or shared class resources.

  3. Manual path

    Enter an absolute or relative path to a local directory or file.

Search & categorization

Filter materials quickly by subject, resource type, or keyword search across titles, descriptions, and custom hashtag tags (e.g. #unit1, #important, #pyq).
