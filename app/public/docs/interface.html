The interface

A quick tour of the layout so you always know where you are and how to get anywhere else fast.

The overall layout

On a desktop screen the app has three parts:

Sidebar
The navigation list on the left. It links to every page: Dashboard, Today, Calendar, Tasks, Study, Habits, Goals, Analytics, Achievements, Timetable, Subjects, and Settings.
Top bar
A slim header showing the current date, the save indicator, quick actions, and the theme toggle.
Main area
The page you're currently viewing — the largest region, where all your work happens.

Getting around

There are three ways to move between pages, and they all lead to the same place:

  • Click the sidebar — the most direct way on desktop.
  • Command palette — press Ctrl + K (or ⌘ + K on Mac) to jump anywhere or run an action by typing. See the Command palette guide.
  • In-page links — many pages link to related places, like a task pointing to its subject.

The save indicator & file controls

You never press "save" — the app autosaves continuously. The top bar features dedicated storage controls:

Control / StateMeaning
SavedEverything is written to your file or browser storage. You're safe to close the tab.
Saving…A change is being written right now. This takes a fraction of a second.
Browser onlyData is currently persisted in your browser's IndexedDB. Connect a local file to sync to disk.
File disconnectedThe browser lost write access to your file. Click to grant permission and reconnect.
Create fileButton in the header to initialize a new JSON workspace file on disk.
Load fileButton in the header to open and load an existing JSON file from your machine.

For the full story on how saving works and what "disconnected" means, see Storage & autosave.

Light and dark mode

Use the theme toggle in the top bar to switch between light and dark appearance, or set it to follow your system preference. Your choice is remembered. (These docs have their own toggle too — try the moon icon at the top right.)

On phones and tablets

The layout adapts to smaller screens:

  • Tablet — the sidebar collapses and can be opened with a menu button.
  • Phone — a bottom navigation bar gives one-tap access to the most-used pages (Home, Calendar, Tasks, Study, and a menu for the rest).

Everything you can do on desktop, you can do on mobile — the controls are just rearranged for touch.

The fastest way to work

Learn one shortcut and you'll use it constantly: Ctrl + K opens the command palette, where you can add a task, start a timer, log study, jump to any page, or export a backup — all without touching the mouse.
