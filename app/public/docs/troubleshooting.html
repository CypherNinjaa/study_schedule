Troubleshooting

When something isn't behaving, start here. Most issues come down to storage access or a browser quirk, and nearly all are fixable without losing any data.

First principle: your data is designed to survive. The app autosaves, keeps a browser mirror, and refuses to overwrite a file it can't read. Before trying any fix below, an export gives you a guaranteed safety net.

Saving & storage

The indicator says "Disconnected" or "Unsaved"

The browser lost permission to write to your file — common after reopening the app in a new session. Open Settings and use Reconnect file, then re-select your data file. Your recent work is held in the browser mirror in the meantime, so you won't lose it by reconnecting.

It keeps asking me to pick my file every time I open it

Some browsers require re-granting file access per session for security. Reconnect when prompted. If it's disruptive, you can rely on browser-storage mode instead — just be sure to export backups regularly, since clearing browser data would remove that copy.

I got a message that my data file couldn't be read

The app detected the file was invalid or corrupt and, deliberately, did not overwrite it — that protects whatever might be recoverable. Don't save over it. Instead, import your most recent exported backup. If you don't have one, keep the original file untouched; a valid earlier version may still be recoverable from it.

I don't get the "save to a file" option at all

Your browser doesn't support direct file access. The app automatically falls back to browser storage, which works fine — see Storage & autosave. For file-based saving, use Chrome or Edge on desktop.

Missing or unexpected data

My data looks empty or reset

Usually the app opened without its file connected, showing an empty state rather than your real data — it hasn't deleted anything. Reconnect your file (or import your backup) via Settings and your data returns. Avoid creating new entries until you've reconnected, so you don't build on the empty view.

An import didn't seem to work

Make sure you're importing a file exported by this app (its own JSON format). Importing replaces your current data, so the app confirms first. If it declined the file, it was likely not a valid export — check you selected the right one.

Streaks, XP & score look wrong

XP didn't increase when I completed something

If you'd completed that exact item before (then un-completed and re-completed it), no new XP is granted — the ledger prevents double-paying. This is working as intended; see XP & levels.

A streak reset unexpectedly

Check the streak's condition was actually met on the missed day (e.g. study target reached, or wake time within the early-wake grace). If a legitimate off day broke it, that's what the weekly freeze is for next time. Streaks are recomputed from your history, so correcting a day's data corrects the streak.

My productivity score seems off for the day

The score blends several factors with fixed weights. A low score usually means one heavily-weighted factor (study or tasks) was low, or the distraction penalty applied. Open Productivity score to see the breakdown and which factor pulled it down.

Display & interface

The layout looks broken or unstyled

The stylesheet probably didn't load — often from opening files in an unusual way. Reload the page. If you're running the app from a local server, make sure it's actually serving the asset files, not just the HTML.

The theme won't stick between visits

The theme preference is saved in browser storage. If it resets, your browser may be clearing site data on close (private/incognito mode does this). Use a normal window to keep preferences.

When in doubt, export first

Before any fix that touches storage — reconnecting, importing, switching modes — export a backup. It costs ten seconds and turns every "what if this goes wrong" into "I have a copy."
