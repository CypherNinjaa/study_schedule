Keyboard shortcuts

Keep your hands on the keyboard. The command palette does most of the heavy lifting, and a few extra keys make everyday actions instant.

The essential one

ShortcutAction
Ctrl + KOpen the command palette — navigate, create, and run actions from one box
⌘ + KSame, on Mac

If you learn only one shortcut, make it this. Almost everything else is reachable from here.

Inside the palette & search

KeyAction
↑ / ↓Move between results
EnterRun or open the highlighted result
EscClose the palette
Just typeFilter instantly — type intent like "add task" or a subject name

Inside the Ebook Reader

KeyAction
→ or SpaceTurn to next page / 3D flip right-to-left
←Turn to previous page / 3D flip left-to-right
EscClose reader and return to Library

On this documentation site

These docs share the same fast-navigation feel:

KeyAction
Ctrl + K or /Open the docs search
↑ / ↓Move through search results
EnterGo to the selected page
EscClose search

Prefer the mouse? Everything a shortcut does is also reachable from the sidebar, top bar, and on-page buttons. Shortcuts are an accelerator, never a requirement.

Build the reflex

For the first week, force yourself to open the palette with Ctrl + K instead of clicking. After that it's automatic, and you'll wonder how you navigated without it.
